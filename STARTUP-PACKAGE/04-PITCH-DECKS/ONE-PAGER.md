# Agent Data Network | Solana-native verifiable data commerce
People contribute reusable licensed knowledge; agents discover metadata and pay only for relevant units. Anchor enforces atomic two-provider payment with an immutable version/content/license receipt per unit. Missing data becomes a funded bounty; requester approval triggers escrow settlement or expiry refund. Private bytes stay off-chain; receipt and wallet proof gate delivery. Initial demo uses fictional solar equipment and a Devnet test mint, no real revenue. Differentiation: combination of atomic contributor settlement, auditable paid entitlement and funded data production. ipto.ai, DataBazaar and Ocean demonstrate established adjacent capabilities; no first-ever claim. Model: proposed 20% commission, 80% provider, buyer pays SOL fees/deposits. Risks: data quality, off-chain availability, receipt rent, demand and legal. Two-day development-first demo; no customer research dependency. Next: verify real program, publish evidence, then online validation before commercial release.
