# Agent Data Network | The Knowledge Economy for AI Agents
Discover → Purchase → Verify → Commission. Contributors publish reusable licensed information, agents find metadata and pay only for relevant units. Anchor enforces one atomic two-provider transaction and immutable per-unit receipt PDAs with exact version/content/license hashes. Missing knowledge becomes funded escrow; local validator checks a synthetic solution without exposing the full answer through API before requester acceptance. Accepted data may later be resold if license permits. Expired unaccepted reward is refunded. Trust metadata identifies self-declared source, freshness and schema validity; accuracy is UNVERIFIED. Private immutable bytes, verified backup and wallet-bound delivery remain off-chain; payment is not atomic with delivery. Proposed 80/20 test split; SOL fees and deposits separate. Distinctive combination, not global-first claim. Initial solar equipment fixtures and local-validator or Devnet test assets only. Guided browser demo and typed agent tools; genuine external agent/MCP and x402 optional. No actual revenue, demand, production audit or verified ownership. Commercial gates after event.
