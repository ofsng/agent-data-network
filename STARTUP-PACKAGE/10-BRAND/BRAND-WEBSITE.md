# Brand direction
Working name Agent Data Network. Category: Solana-native verifiable data commerce. One-liner: Buy knowledge. Verify purchase. Fund what is missing. Promise purchase evidence, not truth or guaranteed rights. Audience: agent builders, contributors, hackathon judges. Dark ink, warm off-white, Solana-inspired mint accent; restrained typography, accessible contrast, no fake dashboards or logo claims. Single guided demo: Discover, Purchase, Verify, Commission, Reuse, Evidence. Explicit runtime mode + synthetic badges, explorer links, price/base unit and SOL fee labels. Primary CTA Run guided demo (browser); secondary View receipt. No real signups or mainnet checkout.

V1.4: Guided browser dashboard is mandatory; CLI is reproducibility support; trust labels show provider declaration, schema validity and accuracy UNVERIFIED. No claim of trusted truth. Bounty preview shows checks only.
