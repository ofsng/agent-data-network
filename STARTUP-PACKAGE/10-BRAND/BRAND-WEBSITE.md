# Brand direction
Working name Agent Data Network. Category: Solana-native verifiable data commerce. One-liner: Buy knowledge. Verify its origin. Fund what is missing. Promise purchase evidence, not truth or guaranteed rights. Audience: agent builders, contributors, hackathon judges. Dark ink, warm off-white, Solana-inspired mint accent; restrained typography, accessible contrast, no fake dashboards or logo claims. Single demo page tabs: Discover, Receipts, Bounties, Evidence. Explicit Devnet + synthetic badges, explorer links, price/base unit and SOL fee labels. Primary CTA Run demo (local CLI); secondary View receipt. No real signups or mainnet checkout.
