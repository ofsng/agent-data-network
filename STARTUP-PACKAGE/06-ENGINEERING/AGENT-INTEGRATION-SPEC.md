# Agent integration — one tool surface
P0 deterministic agent uses actual typed application tools; optional genuine local stdio MCP exposes same tools to Claude Code or another configured client. Solana developer skill/docs MCP is distinct; reuse installed tooling. No API key or model subscription required for core. Live model is a stretch, not a hidden prerequisite. Do not label deterministic trace as LLM reasoning.
| Tool | Inputs / behavior |
|---|---|
| search_data | query, requiredTag; metadata and explicit gap only |
| get_data_quote | allowlisted asset PDAs, maxSpend; exact price, hash, license, source, expiry and SOL estimate |
| purchase_data | quote ID, approved local run; exact signed bundle (or one-unit resale for separate buyer); no generic sign |
| verify_receipt | receipt PDA; decode chain and compare exact expected fields |
| retrieve_data | receipt PDA; wallet challenge internally, hash-verified exact bytes |
| create_bounty | allowlisted requirement, reward, deadline; one per capped run |
| get_bounty_status | public safe status, no private solution |
Requester acceptance, refund, provider publish/activation remain separate operator fixture actions through guarded demo flow. The agent only receives public metadata or purchased bytes. Use fixed policy: cluster/runtime, configured program/mint, isolated buyer, allowed assets/bounty schema, expiry, max token 2,100,000 base units for first run, separately approved SOL cap, one bounty max, allowlisted instructions/recipients. Refund demonstration and resale use distinct approved runs/wallets; no automatic cap replenishment. Persist reservation before signing and signature before sending; use SQLite transaction or single-process serialized durable journal; pending/unknown spends count against cap; only proven failed/not-landed releases token reservation, count actual fees separately. Reject duplicate intent, no automatic re-sign after timeout. No private key in model context/logs, no unrestricted shell signing. Prompt injection in data cannot expand cap or tool list. App caps do not constrain a signer who controls its keys outside app.
